This is a very simple project that shows how to classify breast cancer tumors as **benign** or **malignant** using a basic neural network.

---

## Overview

* Uses the **Breast Cancer Wisconsin dataset** (available in scikit-learn).
* Preprocesses the data (scaling features).
* Builds a small neural network with Keras/TensorFlow.
* Trains the model and evaluates accuracy.

---

## Model

* Input layer (30 features)
* Hidden layer with ReLU activation
* Output layer with Sigmoid (for binary classification)

Loss: Binary Crossentropy
Optimizer: Adam
Metric: Accuracy

---


This project is meant for **beginners** who want to learn how to train a very simple neural network for classification.
